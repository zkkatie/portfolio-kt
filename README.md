# Katie Lim – Portfolio

My portfolio website. I'm a Year 3 Computer Science student (Interactive Media and Game Development) at the Singapore Institute of Technology (DigiPen).

**Live site:** https://zkkatie.github.io/portfolio-kt/

## What's on it

- **WayForge Studio** (in progress): a team tool that turns floor plans into navigable buildings. I built the Studio editor in React and Unity.
- **Mr. Bones**: a platformer on our own C++ engine. I did resource and asset management and audio.
- **Overgrowth**: three Mega Man Maker levels, each paced screen by screen.
- Plus more game, level design and tabletop projects.

## Built with

Plain HTML, CSS and JavaScript, hosted on GitHub Pages. No build step: open `index.html` in a browser to run it locally.
